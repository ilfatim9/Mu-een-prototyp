# Mu'een (مُعين)

Mu'een is a campus support prototype for students with approved health and accessibility needs. It connects student needs with class schedules and facility updates so university staff can review potential conflicts and coordinate support.

## Interface preview

This repository contains a static HTML/CSS preview of:

- Student dashboard, schedule, alerts, support needs, and SOS entry point
- Administration support requests and facility conflict review
- University Health Center emergency overview
- Facilities status updates
- Public SOS page

The pages use sample content. Forms and SOS controls do not submit data in this version.

## View locally

Download the repository and open `index.html` in a browser. No server or database is needed.

## Scope

This repository presents the interface only. The PHP/MySQL functions, authentication, stored schedules, support requests, facility checks, and emergency alerts are not part of this static preview.
